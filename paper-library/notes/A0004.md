# IBAL: Interaction-Breaking Adversarial Learning Framework for Robust Multi-Agent Reinforcement Learning

> 从本对话整理的结构化摘要；不是原始长评逐字副本。历史推导、代码检查和录用信息本轮未复核。

## 作者贡献
将攻击与训练压力从最终回报移向跨代理依赖，用互信息相关量指导观测遮蔽和动作扰动。

## 组合增量
尝试把扰动对应到协作失效机制；关键不只是增加噪声，而是定义被破坏的关系。

## 审计与范围
此前提出完整联合历史下同期动作条件互信息可能为零、条件互信息一般不单调、联合信息可能被逐维指标遗漏及负采样外推问题。构造边界不等于原实验收益不存在。

## 后续方向 1：任务相关交互测量的校准
区分统计依赖、因果影响、必要信息与重建分数。

最小证据：known-zero、XOR联合信息、目标不变干扰变化及支持集负采样检查；固定策略比较指标选择的扰动与真实任务后果。

结果—行动：测量差异必须改变攻击选择或独立训练收益；简单预测重要性足够则不堆复杂MI。

## 后续方向 2：失效—恢复中的必要协作
鲁棒性是可降级后恢复协作，还是长期忽略队友？

最小证据：设置正常—局部失效—恢复三阶段，核验失效后任务仍可解，测绝对任务表现与恢复协作时间。

结果—行动：任务已信息上不可解时先修改目标；不要把低正常能力下的高相对保持率当胜利。
