## 2. 候选A：从显式未来教师到历史位移的函数空间更新

### 生成链
昂贵的合成教师与蒸馏 → 明确它在当前参数处实际产生的更新 → 利用局部算子保留必要作用 → 研究能否在更低资源下保持独立任务收益。

固定前缀、固定教师、全词表reverse KL，在当前学生参数处：

- 当前概率p，anchor概率a，教师q∝p^β a^(1−β)。
- 记当前logit Jacobian为J，C=diag(p)−ppᵀ。
- 精确初始梯度：−∇L=(β−1)JᵀC(f_current−f_anchor)。
- 参数位移Δ足够小时：−∇L≈(β−1)FΔ，F=JᵀCJ。
- logit映射线性时，上式对该参数位移精确成立。
- 默认JSD在局部具有对应的1/4尺度；不能把reverse-KL恒等式无条件移植到完整JSD、top-K、Adam、多步训练。

这是标准局部几何关系的应用，不登记为新定理。F不是F逆；不能称作自然梯度更新，也不能默认它滤除了噪声。

### 最小继续证据
1. 冻结真实checkpoint与前缀，独立计算原始蒸馏更新及局部近似的残差、方向、策略变化。
2. 比较同KL或相近实际位移的直接历史步、原方法及候选算子，区分步长效应。
3. 与已有GRPO-2×和直接外推对照对应，不把已有消融重新包装为新贡献。
4. 只在残差与资源账本支持时，做短程训练，确认独立任务质量与总成本。

候选贡献终点：条件化的更新等价/偏离规律；或确实减少教师构建和缓存开销的实现。二者均须进一步查新。

停止/改写：简单学习率或动量控制已解释收益；近似失真太大；算子计算更贵；实际收益不能独立确认。

## 3. 候选B：针对外推操作设计的有误差控制缓存

### 生成链
当前top-K概率质量高 → 不代表保留了外推会放大的部分 → 分析压缩与非线性外推的非交换性 → 根据外推权重设计存储和误差检查，而非仅增加K。

对一个尾部集合B，p_B=∑_B p_i，a_B=∑_B a_i，r_i=p_i/p_B，s_i=a_i/a_B。

真实外推的未归一化尾权重：
W_B=∑_B p_i^β a_i^(1−β)。

先合并尾桶再外推：
W_fold=p_B^β a_B^(1−β)。

因此：
W_B/W_fold=∑_B r_i^β s_i^(1−β)=exp((β−1)D_β(r||s))。

β>1、正支持条件下，此比值≥1；条件尾分布一致时等于1。这是Rényi散度定义的代数应用，不宣称首次发现。

### 已执行构造
102个token；前100个在p与a中各占0.00995，总计99.5%。

- p尾部=(0.004,0.001)。
- a尾部=(10^-14,0.005−10^-14)。
- β=1.2。
- 全词表外推后再折叠的尾概率：0.456947810776。
- 先折叠再外推：0.005。
- 条件Rényi散度：25.6033429071。
- 未归一化尾权重比：167.447284347。
- 当前分布与压缩教师的JSD=0；与完整外推教师的JSD≈0.1818950091。

极端log-ratio是有意设置的，不能据此判断真实LLM发生率或原文结果有误。附录A.4已经承认尾token可能被提升；候选增量是可计算控制与有效资源接口，不是再次指出存在截断偏差。

### 最小继续证据
固定真实前缀和checkpoint对，比较完整外推/先压缩外推，测尾质量、目标分布和实际更新差异，记录缓存与前向成本。

如存在实质差异，再研究分块扫描、按外推贡献选择token或尾比率边界。不能假设只凭现有top-K+一个尾质量就能恢复丢失信息；新增摘要取得成本必须入账。

完整教师只是算子参照，不是任务真值。压缩可能具有有益正则化作用，因此最终仍需独立任务或已声明系统精度目标验证。

停止/改写：真实偏差很小；完整教师反而更差；通用增大K或流式全词表已足够；新缓存机制代价更高。

## 4. 证据边界补记

- 原文已有额外GRPO更新、直接采用外推参数、去RLVR、anchor、重采样、多种子对照；不重复登记为遗漏。
- 低维不等于可外推；理想线性轨迹下的距离/上界改善不自动保证实际奖励单调改善。
- JSD≤KL/2不能据此从小JSD推出小KL。若仅需回报差，可在相应有限时域/全分布等条件下用TV≤sqrt(2 JSD)重新推导。
- top-K+tail上的小散度不能自动控制原始词表散度；还需要细化误差条件。
- 不增加rollout不等于总计算不增加；匹配反向次数也不等于端到端成本完全一致。
- 不在未知代码、未采真实数据的情况下宣称找到了实现bug或真实失效机制。
