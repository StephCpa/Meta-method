## 1. 作者的贡献结构（分析编码，不是发现历史）

**情境：**固定问题在有限采样下全失败，无法提供正确性差异。  
**对象变换：**不只选题或增加尝试；用教师推理片段把一个问题改成可调辅助量的一族状态。  
**构造：**MFC保存单个非递增的提示上界，从0到上界随机采样，低提示下成功时提交新上界，失败不抬高上界。学生看到hint后仍从头生成完整解答。  
**贡献终点：**在特定筛选语料和模型中，无提示评价与源题目数量效率。不是关于绝对不可解任务的定理。

候选作者码：M2/M6为核心、M5/M3为辅。审查使用M14/M9/M10，三种编码角色分开。

**A+B lift：**教师信息不再仅是固定模仿目标，而是控制训练状态及返回无提示任务的变量。已有AdaBack、R3与SEELE；不能称为首创部分提示或逆向课程。

## 2. 保留原始候选与收敛版本

### A0：让教师产生更可撤除的指导
不预设“提示越短越好”。比较前缀式中间结果、操作式提示和无提示，衡量固定训练预算之后的无提示能力。

### A1：收敛后的主线——提示选择的独立迁移效用
**改变的关系：**从按带提示成功率估计帮助大小，转为直接检验不同提示干预对较少提示和无提示任务的增量。

**具体起点：**在少量可验证问题家族中，为同题制作两种经核验的帮助：
1. 原解答的前缀步骤；
2. 指出待做操作和必要条件，但不直接提供该实例的中间计算结果。

不预设第二种更好。第一阶段在固定策略上记录带提示成功、组内正确性散布和成本；这不构成迁移结果。第二阶段从同参数和优化器状态分支训练，比较独立的无提示新题；至少保留两个短训练时距，避免只选即时效果。

**估计目标：**给定更新接口和资源B，比较 J0_dev(Update_B(theta,h)) 与同预算基线的差值；最终结论在未用于提示选择的新题与训练重复上确认。若使用梯度代理，只把它视作代理，先验证与实际迁移关系。

**首个产物：**一个“题目家族×提示类型×辅助量×固定训练时距”的迁移记录矩阵，而非新loss或大型调度器。

**近邻限制：**AdaBack/SEELE已有自适应提示；LPPO已有prefix与学习进度；GradAlign已有验证梯度对齐。新意必须在稀疏无提示成功条件下，可撤除提示的具体构造、低成本识别与外部迁移；通用validation加权不算新。

**停止/改写：**辅助成功已足够预测迁移；新提示总是破坏可学习性；复杂测量成本超过收益；只改善训练题复现。可保留负结果或提示数据接口，不强求方法。

### B0：把历史成功记录与当前采样控制分开
MFC历史上界不能自动当作当前能力置信证书。保留成功记忆，同时允许当前策略状态被独立审计。

### B1：条件候选，不立即实施
分别维护历史最少提示记录与当前有效性/迁移证据。只有出现持久的无进展或能力回落且复核可信，才允许重新访问较多提示；不能因单次失败就抬高难度区间，也不默认置信阈值越严格越好。

**首个产物：**冻结策略下的控制器null、真实训练中提示撤除后独立表现与回落日志。

**强对照：**原MFC、简单独立确认、固定预算复习/混合、AdaBack；比较同总成本的无提示收益与保留能力。

**停止：**历史状态足够预测当前表现；撤除后的退化不可复现；恢复访问成本抵消收益；简单复习即可解决。

## 3. 已执行的有限状态校准

冻结策略，当前提示上界G=1，每次在{0,1}均匀取g；g=0的8次二值采样至少4次成功则永久进入G=0。这里没有任何模型更新，提示条件下的概率也不变化。

b(p)=Pr[Binom(8,p)>=4]；100次访问后进入G=0的概率为1-(1-b(p)/2)^100。

- p=0：0，零控制通过。
- p=.01：约0.00003389335，即0.003389%，无提示采样质量约.50001695。
- p=.10：约.22239266，无提示采样质量约.61119633。
- p=.20：约.94241160，无提示采样质量约.97120580。

所有情形的真实无提示成功率始终为p。精确Fraction运算结果见JSON。

**解释：**课程变量可以变化而能力不变；这只校准指标解释，不证明原论文曲线来自此机制。p=.2是可能的后期局部状态构造，不代表最初pass@64=0筛选概率。处于p=.2时增加无提示练习也可能有益，不能把进入G=0自动叫作错误。

附带二值指标检查：n=8，至少一次成功概率为1-(1-p)^8，混合正误概率为1-p^8-(1-p)^8。p=.99时前者近1、后者约.0772553。真实算法有长度惩罚和KL，不能将二值正确性为常数等同于整个更新为0。

运行：
```bash
python calibration.py
```
仅标准库、无GPU、无网络。脚本是本轮独立实现，不是作者训练器。

## 4. 不应误写的结论

1. Unsolvable为指定策略、生成预算和配置下未采到成功，不是数学支持为零；不同尺寸模型不能仅凭总体强弱继承逐题难度。
2. 约16倍指训练源题目数2000/128，不能改称计算或全部信息16倍节省。原筛选需评估2000题×64生成，还有教师步骤与训练费用。
3. 同步数/同硬件与完整总成本须分别报告；SFT对照存在，但不排除一切蒸馏方案。
4. pass@k有限预算覆盖不证明同题新策略或从绝对零支持创造能力。
5. 附录F已说明有提示梯度迁移符号不定，并说明MFC的g=0访问重加权了问题分布；不再作为“作者没注意到”的缺口。
6. AdaBack原方法已有p_zero=.1的无提示阀门；MFC新意不能说成第一次考虑无提示分布。
7. 单调的是每题控制状态和相应条件采样概率，不是模型能力或每个batch的观测比例。
8. 正确性奖励差异、长度惩罚差异、KL更新应分开记录。
9. 多次评价生成不替代独立训练seed；来源选题与确认数据分开。

## 5. 最小真实材料与资源

先固定一个可运行学生模型、少量问题家族、提示内容和采样配置。作者Uns-128数据卡包含question、ground_truth、steps、teacher_full_output等，但最终答案通过不证明每步推理正确。对选定子集核验提示，再做独立样本的两种帮助比较。

需要记录：问题与家族ID、checkpoint/优化器状态、提示类型和hash、g和总步骤数、raw reward/长度惩罚/KL、group成员、controller前后状态、teacher查询、tokens、训练与评价成本、数据角色。

顺序：材料核验→固定策略读数→小规模真实更新迁移→只在缺口成立时开发提示选择或恢复机制。固定策略生成不能证明“可学”；短期为零不证明长期无用。

## 6. Meta-method沉淀候选

生成操作：当一个目标端点当前不可达时，不立即换目标或无限重试；尝试构造可控的邻近问题族，并把返回原始条件的机制作为贡献的一部分。

检查：辅助下成功、得到学习信号、学到可迁移能力、撤除后稳定，是不同对象。检查用于选择下一步，不要求原论文证明所有层级才能有价值。
