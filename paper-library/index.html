论文分析库

保存贡献拆解、证据边界与值得继续追问的问题，而不是堆积原论文。

v0.4.0 方法 · 本地优先

数值只代表原分析对后续主线的历史判断，不是论文质量，也不自动属于每条方向。未评分不等于 0 分。

下一篇，继续追加

填写后导出一份导入单；运行一次本地命令即可入库。相同 arXiv / DOI 追加分析，不覆盖旧记录。此页面不自动改写硬盘文件，也不上传内容。

把 JSON 放入 inbox/，在论文库目录运行：
python3 tools/library.py add inbox/reading-intake.json
新增评分时另用 rate 命令填写理由；不会将未评估方向自动打分。

保存判断，也保存判断的来路

本库整理已有分析，不在这次建库中重新核验论文、会议或所有旧实验。文件中的原文数字和论断是来源记录，不自动等于独立证实。MAS长评与部分跨领域对话仅保存明确标注的摘要；其余已有分析档案保留正文。

结构：一篇论文可以有多份分析；一条研究方向可以连接多篇论文。论文级历史潜力与方向级评分分开存储。加入新材料时保留旧分析与评分历史，不重置已有记录。

本页可以断网使用；只有手动点击原论文或来源链接时才会访问外部网站。浏览器没有服务器保存功能；导出的JSON必须使用本地工具入库。
Meta-method · 贡献生成 × 主张审计 × 研究决策。数据为开发积累，不是独立有效性试验；未发表方向默认保留在本地。
