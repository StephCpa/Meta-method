# v0.3.0 工作版本

发布日期：2026-09-30。当前状态：框架和工具可试用；独立前瞻有效性尚未验证。

## 范围

五层架构、十二条条件化规则、M1–M14纳入／排除说明、六类主张证据配置、条件化附页、主张和规则修订模板、48条开发候选、6个填写示例、12个公开构造案例、三臂拟议协议、结构验证及内容冻结工具。

## 来源与变化

基于用户给出的MAS对话、OPD报告／v0.2附件和跨领域经验整合。原术语、编号、OPD分组及奖项的来源陈述保留；科学核验状态未升级。v0.2正文逐字归档，新解释见CHANGELOG。

## 不包含

没有重新审稿48条材料，没有重新确认全部奖项和版本，没有新增模型训练，也没有执行三臂前瞻试验。原始历史探针未由本版单元测试重跑；历史附件哈希清单与独立快照包用于保存材料。

## 验证

运行 `python3 tools/validate.py` 和 `python3 -m unittest discover -s tests -v`。本次实际运行摘要见同目录的 `local-validation.json`；CI状态须另查GitHub，不能由本地结果代替。

工程验证只检查结构、ID、引用、开发集隔离与工具行为。它不计算框架的科学有效性、论文新颖性或接收概率。

## 下一步

先用公开构造案例培训评价者和修订量表，再选择新的问题家族与未知结果决策。拟议样本量需单独检查；冻结哈希不是正式预注册。若完整代码本不优于仅有主张契约与证据分支，应考虑简化框架。
