# Meta-method v0.4：生成贡献、审计主张、选择下一步

状态与来源边界见 [STATUS](../STATUS.md) 和 [provenance](provenance.md)。

## 0. 两个互补模块与决策接口

**贡献生成**从问题情境、瓶颈或机会开始，不强求先有精确主张。用[生成卡](../generation/move-cards.md)提出“对象／限制→具体变换→新增结果→第一个产物”，保存未经审计的候选。

**主张审计**在候选形成后拆分具体主张，沿以下五层匹配证据。**研究决策**比较可执行的下一步和预算，不把审计更谨慎当作生成更好。生成和审计可来回迭代，原候选与改写版本分别保存。

生成的单位是机会情境；审计的单位是主张；投入决策的单位是候选集合与下一项行动。三者不互相替代。[双轨评价](../evaluation/README.md)分别检验各自增量。

## 1. 研究目标先于证据模板

审计的基本单位是一项重要主张，不是整篇论文。一篇算法论文可以同时提出数学、工程、机制和部署主张；它们分别需要相应证据。一个纯表达复杂度结果不因缺乏训练提升而不成立；一篇自称系统工作的论文若提出因果解释，仍须承担机制证据。

先写“要获得哪一种新认识或新能力”，再写“什么改变使它成为可能”，最后选择证据。诊断、构造、观察和实现可以交替发生，不约束实际发现的时间顺序。

## 2. 五层结构

| 层 | 职责 | 不应做什么 |
|---|---|---|
| 共同原则 | 对象明确、假设显化、证据匹配、边界清楚、允许修订 | 规定所有项目相同的终点 |
| 主张契约 | 记录对象、比较项、成果类型与最低成立标准 | 按论文自称类型免除其余主张 |
| 操作代码本 | 提供 M1–M14 可选动作 | 用贴码覆盖率证明效果 |
| 证据配置 | 按具体主张路由证据 | 要求每项工作填满所有附页 |
| 投入和版本管理 | 选择下一项证据行动，记录完成／修订／停止 | 把探索改题冒充事前预测 |

## 3. 十二条条件化规则

### R01：明确主张契约，而不是先列组件

记录研究对象、条件、目标或估计量、分析层级、参照的性质、预期贡献和资源约束。真值、权限规范、偏好与代理指标不可互换。多元任务不强行制造唯一参考，也不因此取消任务约束。作者声称的每一项结论单独承担证据。

### R02：允许诊断入口与构造入口

发现失败并非唯一入口。新计算原语、可省略中间对象、未利用反馈、新数据或仪器都可以成为起点。须说明新增认识或能力，而非新组件数量；构造也可能产生此前无法观察的现象。

### R03：机制名称首先是假说

当声称某种机制时，构造不含该机制却可能产生相同症状的参照，并写竞争预测。纯构造／性能主张不被强制附加心理或因果故事。简单机制已能解释现象时，收紧解释而非否定所有研究价值。

### R04：在真实目标层级上使用 M14

区分对象定义、观测可辨性、结构可识别性与有限样本精度。弱局部单元不自动否定可估计的总体目标；总体估计也不自动解决任意局部不可识别。未检出不等于不存在。闸门限制强结论，不普遍禁止扩展支持集或创造观测能力的探索。

### R05：测量既要敏感，也要对无关变化稳定

适用测量主张时，加入目标为零的负控制、有实际意义效应大小的正控制，以及目标不变而措辞／长度／角色／格式变化的检查。机制存在但指标看不见的反例同样重要。群体差异可能是目标的一部分，不能只提高一致率来“去噪”。

### R06：证据绑定对象、条件、时点与抽样过程

记录被评分内容版本、上下文、模型／教师／策略版本和采样机制。变换后旧证据不能自动继承；旧分数仍数值正确，也可能不再代表当前分布。区分来源标签、当前状态和实际影响。文件哈希证明字节一致，不证明科学正确。

### R07：变换后的目标与更新分别审计

过滤、裁剪、归一化、重加权、局部近似及缓存可能改变目标。区分同一目标、同一期望梯度、同一更新、同一固定点和同一部署效果。有意偏差可改善有限预算表现；不能把有偏自动判错，也不能把稳定性当作原目标保证。

### R08：执行与权限必须是真实的

声称阻断、回滚、重置或澄清时，检查实际输入、状态和副作用。记录干预前提与权限成本。图上删边不等于消息未送达；提醒不等于真正暂停；组装不等于最终越界。该规则仅在存在相应执行主张时启用。

### R09：建立不循环的确认

不断变化的对手、反馈、判别器和策略需要适当固定参照。实证可使用未参与选择的数据；理论可用独立证明检查、形式化或反例；系统可用独立实现和工作负载。独立确认不等于所有领域必须有测试集，单元测试也不等于独立科学确认。

### R10：匹配主约束，完整报告代价

机制实验控制混淆资源；系统比较允许重新分配预算。预先声明主约束并记录初始化、标注、教师、计算、通信、核验和部署成本。理论工作可用明确成本模型，不强求 GPU 实验。最小证据不是最便宜证据，不回避不可拆分的建设成本。

### R11：按贡献终点完成，而非统一要求新算法

理论界限、经验解释、方法、系统接口、数据资源与决策规则都可独立成为终点。成立性与价值性分别判断。当前贡献完成后无需强行生成三条后续线；没有重要缺口是合法结论。仍须处理该贡献实际提出的全部主张。

### R12：以知识或决策增量决定下一步

区分决定下一步的最小证据与完成贡献的充分证据。记录结果—行动分支、完成条件及重启条件。探索允许新发现和改题；保留版本，后续用适当新证据确认。审计误停，不把没有执行的项目自动算成节约。理论新认识不需强行折算成部署收益。

## 4. 最小判别证据不等于最终充分证据

| 当前行动 | 足以改变下一步的证据示例 | 最终仍可能需要 |
|---|---|---|
| 决定是否保留一个全称命题 | 一个有效反例 | 新命题的完整证明 |
| 决定是否建设系统 | 正确运行的最小原型 | 目标规模、可靠性、端到端成本 |
| 决定如何定义评价目标 | 小规模群体访谈或分歧分析 | 覆盖、招募、标注和独立效度 |
| 决定教师／估计器 | 固定前缀或精确梯度检查 | 预算匹配训练与目标表现 |

不是所有研究都必须做 toy、随机试验、消融或大规模训练。何种检验必要，必须能回指具体主张。

## 5. 适用与不适用判断

允许 `not_applicable`、未知、两种合理编码和空编码。来源尚缺时标记未知，不用模型常识补成原文结论。缺少某项证据可限制该结论，而不自动终止低成本探索。已经作出的弱主张，不因未支持一个更强主张而自动失败。

## 6. 框架自身的证据边界

MAS 十篇、OPD 24条及跨领域14条均已用于规则形成，全部是开发材料。它们不代表随机样本，不用于估计顶会流行率或泛化成功率。另一个 GPT 对话不是独立实验。描述与诊断可执行性由MM-P01检查；生成、筛选与前瞻决策由[MM-G01](../evaluation/generation/MM-G01-protocol.md)另设任务。获胜论文恢复不是唯一答案，也不是当代新颖性证明。
