# 来源与证据追溯

当前边界见[STATUS](../STATUS.md)。原材料不可静默修正；来源类型不构成统一科学等级。论文网址是查核入口，不自动表示本轮查核。

## 三层记录

`data/cases.json` 保留48条历史开发条目和原review/proposal状态。`data/author-moves.json`另存八篇作者贡献的首轮来源锚定记录，逐条保留原文版本、定位、编码理由与边界；其阅读动作来自工作包，发布只做导入和工程核验。`external_annotation`记录审查者C码，不能自动转换成作者M码或完整目录定义。

规则的[data/rule-lineage.json](../data/rule-lineage.json)区分回溯说明、边界反例及有效性证据。目前只有前两类；不重建未经记录的真实启发历史。全部规则保留[R01–R12](../data/rules.json)编号。

## 来源材料

SRC-MAS为十篇MAS对话；SRC-OPD为24篇报告；SRC-CROSS为14条跨领域对照。初始32篇以及另一对话10篇后训练种子没有完整可见清单，不补写成新样本。SRC-REVIEW-031为[外部审查](../archive/review-v0.3.1.md)；SRC-V04-WORKBENCH为提供的首轮贡献工作包；SRC-V04-INTEGRATION为本次结构整合。

另一个GPT对话不算独立重复。构造反例只能约束相应推论，不能代替原论文经验效应估计。代码快照问题不自动推翻未对齐版本的发表表格。检查完成与支持结论分别记录。

## 历史附件

[旧清单](../archive/manifest.json)记录外部交付附件的字节哈希，其中只有明确repository_copy的文件在仓库。它不是下载页面；缺失的ZIP不参与本版测试。历史提交与发布说明保留，不把对话交付文件伪装成本仓库能力。最新维护入口不依赖这些外部包。

## 核验升级

新增真实查核时记录source_version、locator、action、date及未覆盖范围。现有记录保持不动或保留修订历史。奖项、实验、新颖性和发现历程各自需要对应来源。代码测试只证明被测试的工程属性。
