# 六类主张的证据配置

配置作用于一项主张，不作用于整篇论文。下面是条件化最低要求的起点，不是机械清单。混合主张分别审核；使用某个类型名称不能免除另外的主张。每项研究还应分别讨论成立性与价值性。

| ID | 目标 | 典型核心证据 | 不应机械要求 |
|---|---|---|---|
| `theory` | 定义、刻画、上下界、表示与逻辑关系 | 模型与量词、完整证明或构造、条件依赖、边界例、已有结果关系 | 没有部署主张时补真实模型训练 |
| `explanation` | 理解自然、认知或系统现象 | 竞争解释、可区分预测、适当观察／干预、独立条件预测 | 必须制造更强产品模型；相关即因果 |
| `algorithm` | 新估计器、数值或优化方法 | 目标与更新对应、正确性／误差／复杂度、数值检查；声称任务增益时再验证任务 | 必须先发现指标失败；无偏自动更好 |
| `system` | 新执行能力、效率、可靠性和接口 | 真实执行、端到端成本、工作负载、容错与信任边界、复用能力 | 所有组件都原创；FLOPs 自动等于真实加速 |
| `data_evaluation` | 新任务、数据、测量或评价协议 | 目标效度、采样与覆盖、来源及标注、群体差异、重复性和下游用途 | 必须提出最强算法；所有分歧都是噪声 |
| `decision` | 改善选择规则与资源分配 | 决策目标、选择／评价分离、效用与风险、成本、不确定性和目标人群 | 每个局部单元先显著；训练损失代替决策价值 |

## theory

“对所有类存在下界”与“存在一个类达到上界”分开；充分和必要分开；平均、逐点、最坏情况及条件保证分开。验证引用定理的全部条件，而非仅递推形式相同。假设需要在目标应用中检查，但假设不是天然漏洞。证明完整且增量重要可以标为完成，不必扩展实验。

## explanation

先确定模型是产品、研究仪器，还是研究对象的近似模型。噪声可能是被解释系统的真实约束，而不是要消除的误差。干预不可行时，说明可用观察的识别边界；不强迫随机化不可操控对象。独立证据应对竞争解释有判别力，不能用自述意图代替行为机制。

## algorithm

区别目标、随机估计器、停止梯度、近似、优化器、固定点和部署终点。同一期望更新不保证同一有限步效果。数值精度、稳定性与实际复杂度另行检查。新的数学结构或估计方法可以独立有价值，性能结论只在实际测试条件中成立。

## system

比较真实运行而非仅抽象图。分清信任组件、输入读取与副作用边界；计入预处理、构建索引、缓存、标注、通信、回滚、部署等成本。规模扩大与复用能力可构成贡献；资源建设可有不可拆分前期投入。最小原型只支持继续建设，不证明大规模可靠。

## data_evaluation

先分清真值、规范、偏好、群体语境与代理指标。“评委一致”不自动表示定义有效。分析招募、缺失、选择、标注流程与模型辅助标注造成的循环。允许合理多元参考及分层报告。测量目标变动应版本化，不用新标签静默重写旧结果。

## decision

先写估计层级和选择空间。单次实验弱不自动否定跨实验规则收益。置信区间、检验与停止方式服务于真实决策，不以显著性作为唯一门槛。报告错误继续与错误停止；停止项目缺少结果时不得自动算作避免浪费。对照应是合理强基线，而非故意随意的流程。

## 混合主张示例

“估计器无偏、内存少一半、提高任务成绩”至少有三个证据义务。一个证明不能自动证明速度，速度测量不能证明机制，任务成绩不能证明无偏。反过来，缺乏任务实验不否定它已经建立的数学主张。

## 完成的最低判断

列出已支持主张、仍未知主张、不适用要求。当前核心贡献与其合理范围已经匹配时，可以完成；删除未经支持的附带故事，不必永远增加实验。审查者也须指出为什么一个要求必要，并允许作者以更窄主张回应。
