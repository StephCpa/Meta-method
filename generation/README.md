# 贡献生成工作流

本模块回答“可能创造什么”，审计模块回答“需要什么证据”。来源与有效性状态见[STATUS](../STATUS.md)。

## 四步开始，不急于筛掉想法

1. 写下重要机会、已知瓶颈及最接近先行工作，不强求精确主张。
2. 从[六张操作卡](move-cards.md)选择值得尝试的关系变化，或记录无匹配；不要只输出“做M2”。
3. 用[机会模板](../templates/opportunity-to-contribution.md)写具体对象、变换、可能增量和首个产物。组合用[M13卡](../templates/m13-lift-card.md)说明增量，不要求统计超加性。
4. 保存原始候选，再转[贡献—证据卡](../templates/contribution-evidence-card.md)。审计可以修改或否定主张，但候选版本不能丢失。

卡片可用于已知目标的新方法，也可用于新任务、工具、观察与理论边界。未验证是状态，不是自动否决；过早检查只能限制强主张，不能替代低成本探索。

## 来源与空缺

[八篇作者卡](../cases/author-moves-eight.md)是单轮提取的贡献结构，不是作者发现历史或八次有效性试验。[外部映射](../data/external-review-crosswalk.json)未取得完整C定义。证明界限、赋能工具和重新启用旧原语在旧M码中仅部分适配，保留具体自然语言操作。

真实使用者情境、现实对手视角和有价值的否定／简化等尚需更广社区的来源，不伪造成熟卡。M编号不变；操作卡的slug只是文件标识，不是新增分类体系。

## 评价

[MM-G01](../evaluation/generation/MM-G01-protocol.md)以机会情境为单位，在固定候选预算下评价合格方向，已知赢家仅为辅助参考。固定池审计单独评价保留和筛选；未选择每个好候选不是自动误杀。
