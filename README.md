# Meta-method · v0.3

**共同研究原则 × 主张级证据分支 × 条件化操作规则**

> 先确定要获得哪一种新认识或新能力，再确定哪些改变使它成为可能，最后用适合该主张的证据验证。

版本：**0.3.0** · 日期：**2026-09-30** · 状态：**可试用的研究决策框架；有效性尚未经过独立前瞻验证**。

这不是“所有好论文必经的一条流水线”，也不是自动审稿器。M1–M14 是可重叠的操作代码本；是否使用某个操作、需要哪一种证据，由具体主张决定。理论、解释、算法、系统、数据／评价和决策研究具有不同的完成标准。一篇论文可以同时包含多类主张。

## 一张卡开始，不必填满所有附页

先写问题／机会、核心主张、贡献终点、当前证据、下一项最有价值的证据行动。只有相应主张需要时，才启用学习契约、权限账本、量词检查或人群评价附页。代码允许为空，证据允许尚缺，也允许当前贡献已经完成。

**三种编码不得混计：** `author`（作者实际采用）／`review`（我们用于审查）／`proposal`（建议的后续操作）。

**两种证据目的不得混计：**决定下一步的最小证据，不等于完成最终贡献的充分证据。

## 本版交付

- 共同原则、六类主张证据配置、M1–M14 纳入／排除规则与条件化契约。
- Markdown 与 JSON 主张模板、规则修订模板、六个填写示例。
- 10 篇 MAS、24 篇 OPD、14 篇跨领域候选的开发材料登记；它们不是 48 次独立有效性试验。
- 12 个公开构造案例与三臂比较方案；这些是开发／培训材料，不能用于宣称未见领域泛化。
- 标准库验证器、单元测试和协议内容冻结工具。通过测试只表示工程一致性，不表示科学结论或工作流有效性已获证实。

## 本地检查

```bash
python3 tools/validate.py
python3 -m unittest discover -s tests -v
python3 tools/freeze.py --out outputs/protocol-freeze.json
```

Python 3.10+；不调用模型、不联网、不安装依赖。冻结文件只提供内容哈希，不是外部时间戳或正式预注册。公开构造案例的答案不应交给未来确认任务的执行者。

## 证据与来源边界

本版基于用户提供的对话材料、OPD 报告及既有附件整合。**没有在本轮重新核验全部论文、奖项、代码快照和旧实验声明，也没有新增模型训练。** 论文网址是查核入口，不等于已完成查核。历史评分仅表示当时资源条件下的主观投入优先级，不是论文质量或接收概率。

参见 [来源登记](data/sources.json)、[历史附件清单](archive/manifest.json)、[版本记录](CHANGELOG.md) 和 [权利说明](RIGHTS.md)。完整历史附件保留在本次交付的独立快照包；仓库清单记录其逐文件哈希，不伪装成已导入的工作代码。

## 本版最重要的修订

v0.2 的“固定资源下部署结果”改为**仅对提出部署主张的研究适用**。允许证明、解释、数据、公共工具和新计算原语独立构成贡献；支持集闸门针对真实估计层级；分歧不自动等于噪声；发现顺序不固定。

没有商业或科学效果保证。欢迎记录规则失效、合理的不适用案例，以及框架产生的不必要要求，而不只是记录它找出的缺陷。
