# 两条评估轨道

| 轨道 | 对象 | 主终点 | 不能支持 |
|---|---|---|---|
| [MM-P01](pilot-protocol.md) | 已形成主张的审计 | 必要证据漏项、严重过度要求 | 提出了更好的研究方向 |
| [MM-G01](generation/MM-G01-protocol.md) | 机会情境→候选→选择 | 固定预算合格候选、固定池保留、真实下一步增量 | 仅猜中赢家即具备当代新颖性 |

两轨均未在本仓库完成效果试验。旧计划不改名为生成评价。模型、材料、评价人员、阈值和功效须在各自运行前绑定。历史包须记录最早公开日期和事后选材风险，模型截止日期不是未见证明。

参与者只接收材料清单内的中性正文；文件名、臂名、他臂说明、优劣预期、评价参考不进入输入。评委副本再移除代码元信息而不重写论证。内容仍可能暴露方法，不能宣称完美盲法。

审计三臂维持实际包效果解释，输入量差异计入成本；欲识别结构独特价值，需要有意义的同预算主动对照，而非无关填充。MM-G01已定义G0强通用生成指南与G1操作卡，具体token与执行参数仍未绑定。
