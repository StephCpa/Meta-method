# 主张级框架包（B/C相同）

共同原则：目标明确，假设显化，证据与结论逐项对应，边界清楚，允许修订。核心记录单位是主张，不是整篇论文类型。

贡献—证据简卡：
1. 问题或构造机会为何重要？
2. 准备获得哪一种新认识或新能力？
3. 对象、分析层级、参照性质及资源约束是什么？
4. 相对既有工作的增量及最低成立标准是什么？
5. 当前证据支持到哪一步？哪些常见要求不适用？
6. 下一项证明、构造、原型、观察或实验能改变什么判断？
7. 独立确认、完成、暂停和重启依据是什么？

相关时使用相同附页。测量由诊断转为训练、样本选择、路由或停止规则时重新检查效度；区分目标真实变化、样本变化、测量工具变化与标签变化。复验完成不自动意味着指标有效。没有反馈影响则不强求新增训练。

贡献成立性和价值性分开。局部弱信号不自动否定总体估计；真正的语境偏好差异不自动视为噪声。最后根据相应证据判断，不要求所有工作都改善部署模型。
