# 研究方向形成指南

从具体问题、先行工作和资源约束出发，按触发条件选择操作；不需要逐项套用，也可以提出未列出的路线。每项操作都必须落到一个关系变化，而不只是给方案命名。当前不确定性允许保留为探索条件。

**改变比较维度。**当“能不能做”掩盖差异时，比较描述规模、验证成本、信息访问或资源要求。先用严格定义的对象构造分离；仅增加一个与旧指标等价的数值不算新关系。

**直接处理可观测量。**当目标依赖无法取得的变量时，先在实际可观测对象上定义目标，再研究何种条件足以约束原问题。第一个产物是目标关系及其计算路径，不能承诺无信息情况下无条件恢复未知量。

**绕开完整中间对象。**当昂贵结构的下游只用一个收缩、判别或函数量时，尝试直接计算或估计其作用。先核查省略的部分是否真非必需，产物可以是恒等式、误差界或原型。隐藏到另一处计算不算节省。

**寻找界限与构造。**当改进持续遇到同一障碍时，寻找最坏情形、反例或匹配上界。保留全称与存在量词以及允许的模型条件；一个局部构造能指导下一步，但个人没跑通不是不可能性证明。

**创造研究工具。**当数据、观测、交互或可执行规模阻碍问题时，建设可产生新研究材料的接口或反馈闭环。先明确使用场景、建设成本和独立评价。原型与数据相互促进可能有价值，换名和下载量不能代替新增能力。

**从执行约束反推结构。**当理论优势不能兑现，或成熟原语受旧实现限制时，围绕访存、并行、构建／查询和训练兼容性改写组织。固定目标工作负载并分开算法、实现和资源贡献；更多资源形成新规模可以有价值，但不能不记账。

对选中的变换写出最近的简单参照、新增结果和首个产物，再比较预算下的可行性。组合必须解释改变了哪个关键关系，不要求统计超加性；提案尚未确认是状态，不是自动否决。保存未经审核的原始候选，不能以标签或篇幅替代贡献。
