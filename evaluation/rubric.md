# 评价单位与量表 v0.3.1

本版定义评分方法，没有提供任何真实三臂试验结果。评分对象是分析输出，不是原论文作者。语义匹配和严重度由盲评者决定，工具只做已标注结果的算术汇总。

## 1. 必要证据单元

每案例在确认前由独立领域评价者冻结有限清单：每个单元包含ID、对应主张、必要要求及理由、可接受的等价表达、适用条件。按一种独立证据义务计数，不按句子、段落或拆成多少条计数。一个泛泛的“多做消融”不能自动覆盖所有单元。实际输出与单元的对应由人判定为met／missed／not_applicable／unjudgeable；重复表达不会增加分母。

案例漏项率 = missed / (met + missed)。没有适用单元时为NA；unjudgeable另报，不默认为met。主汇总使用有定义案例的宏平均，并报告NA与争议数量及覆盖差异；同一case的多个义务不是独立样本。确认中发现参考清单错误，登记争议、进行预设敏感性分析，不按各臂结果修改答案。

## 2. 不必要要求没有虚构的无限分母

盲评者将无依据的行动按“对象＋动作＋目的／新增义务”语义去重，分配稳定action_id。重复三次、拆成五句仍是一项；不同的额外实验即使措辞相似也不得合并。严重度：1=可省的辅助工作；2=足以改变主要判断、错误否决或显著增加投入。0属于没有该问题，不进入无依据行动列表。

共同主终点是每案例是否至少有一项严重不必要要求，跨完整评价案例求发生比例。次要终点为每案例去重后的无依据行动数、严重度分布和成本。评价未完成时这些值为NA而不是0。若另用预设陷阱清单，只能报告该有限清单的命中率，并额外登记清单外问题；不把它叫所有过度要求的错误率。

## 3. 其他维度单独报告

贡献误读、来源越界、下一步行动可执行性、合理完成判断可沿用0/1/2人工量表；严重度不是错误率的分母。不要随意合成单一总分。两名评价者独立标注再按冻结规则裁决；记录一致性、争议与原始标注，不能只保留多数意见。

## 4. 比较和不可判断

定义gain = omission(B)−omission(C)，越大越好；risk_change = severe_overreach(C)−severe_overreach(B)，越小越好。确认前填写有意义改善阈值δ和容忍界限η，不在本补丁里虚构数值。使用对配对case／项目簇有效、并处理共同终点的区间方案；统计方案与样本量需在正式确认前另行锁定。

- 支持改善：gain区间下界≥δ，且risk_change区间上界≤η。
- 足够精确地排除可接受改善：gain上界<δ，或risk_change下界>η。
- 其余：不可判断。

这只是给定有效区间后的决策逻辑，不证明输入区间有效。主张有效性和资源选择分开：不确定时可因成本偏好简单流程，但不能称代码本被证伪。每个比较B−A、C−B、C−A分别分析，不把包效果归因于单组件。

对应算术帮助函数见 [tools/evaluate.py](../tools/evaluate.py)；没有模型裁判或关键词自动科学评分。
