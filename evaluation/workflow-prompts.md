# 三臂提示配置

状态：开发草案。实际试验前冻结版本、共同材料、预算、检索权限和输出上限；不能边看确认结果边改提示。

## 共同输入与输出

输入：同一个截止时点的材料包、研究目标和资源限制。禁止访问其他臂输出、未来结果或参考答案。只根据可得材料作结论，未知明确标注。

输出上限与分析预算由执行配置统一给定。输出包含：核心贡献；已支持与待支持主张；必要与不适用证据；最有价值的下一步或“当前已完成”；来源和不确定性。不要为了填满数量而虚构缺陷或后续方向。

## A — 通用高质量清单

请准确概括研究主张及相对已有工作的增量。检查理论或实证正确性、假设、合理对照、统计与实现、可复现性及局限。给出必要的改进建议，区分重要问题与可选延伸。考虑成本和独立验证，并尊重材料的研究目的。

## B — 主张级证据路由（无M代码）

对每项重要主张建立对象、条件、贡献终点和最低成立标准；选择理论、解释、算法、系统、数据评价或决策证据，可混合。区分最小下一步证据与最终充分证据；允许诊断或构造入口。检查观测过程、参考性质、执行和资源，避免过度要求。记录完成、改写、暂停及重启条件，不使用M编号。

## C — 完整Meta-method

使用与B相同的主张级路由，再选择M1–M14中确有用途的操作；分别记录作者已采用、当前审查、未来建议。每项编码需锚点和纳入理由，允许空编码、不适用与多种合理判断。仅在主张需要时启用相应条件化附页。最终面向判断与行动，而非贴码数量；盲评副本去掉代码与臂标签。

## 实验解释

A和B也应有同等检索与推理机会，不能用“随便总结”代替强对照。B–A、C–B、C–A分别回答不同问题。内容长度不同并不自动意味着预算不同，必须记录实际token、工具调用和时间；不要让C暗中获得额外材料。
